# Форматы TamEngine (BLEACH Rebirth of Souls)

Все смещения — от начала распакованных данных, little-endian.

## PZZE (обёртка)
```
char[4] "PZZE"; char[4] формат ("tmd2", "lds", ...)
u64 размер распакованного; u64 смещение данных (обычно 24)
zlib-поток
```

## LDS (текстуры)
```
u32 dataStart; u32 count; u32 fileSize; u32 offsets[count]
DDS[i] начинается с 12 + 4*count + offsets[i]
```

## TMD2 (`tmd0`)
Заголовок: `flags` (u16 @6), `version` (u16 @10), bbox 6×f32 @16,
смещения моделей/записей/материалов/параметров/имён/подмешей/треугольников/
текстур/вершин, затем количества; при `flags & 0x2000` — блок скелета
(таблицы индексов, матрицы, иерархия, количество костей, extra).

Вершина по флагам (по порядку):

| флаг | поле |
|---|---|
| 0x2 | pos 3×f32 |
| 0x400 | веса 4×u8, кости 4×u8 |
| 0x8000 | ещё 4 веса + 4 кости (до 8 влияний) |
| 0x4 | нормаль 4×u8 |
| 0x8 | тангент + бинормаль 2×4×u8 |
| 0x80 | цвет 4×u8 |
| 0x100 | нормаль 2 (рендерная) 4×u8 |
| 0x200 | цвет 2 4×u8 |
| 0x10/0x20/0x40 | UV0/1/2: 2×f32 при 0x1000, иначе 2×i16 / 1024 |

Треугольники: u16 (или u32 при `0x800`). Подмеш = (кол-во треугольников, начало).
Модель = список записей (u8 индекс, u8 тип): 96 материал, 64 таблица индексов
костей, 48 подмеш, 16 конец. Индексы костей в вершине — это индексы в текущей
таблице (так обходят ограничение u8 при >256 костях).

Кость (24 байта): u32 hash, 3×f32, i32 parent, u16, u16 смещение имени.
Матрица кости — **обратная bind-матрица** 4×4 (строки-векторы, как Matrix3 в Max).
Хеш имени: CRC32-таблица, начальное значение = длина строки, без инверсии.

## TACTPKG / TMO
`actmng_pkg`: записи (char[64] имя, u32 смещение, u32 размер); подпакет
`acttmo_pkg` содержит клипы `tmo1` в том же виде. Заголовок любого `act*_pkg`:
char[16] тип, …, u32 число записей @32, записи по 72 байта с @36.
Другие подпакеты: `acttmv_pkg` (вершинная анимация), `actmtl_pkg` (анимация
материалов — UV/цвет/прозрачность, эффекты), `motblend_file`, скрипты. Формат
записей `acttmv`/`actmtl` пока не разобран — плагин только перечисляет их в логе.

`CATS` (`.cat`, архивы карт/объектов): `CATS`, u32, u32 число записей,
u32 смещение заголовков (от @16); записи (u64 смещение имени, u64 смещение
данных, u64 размер), каждая выровнена на 16. Записи бывают вложенными `CATS`,
`tmd0`, `PZZE`, `act*_pkg`, `tmo`.

`tmo1`: на кость 9 кривых (позиция XYZ, поворот XYZ — эйлер, масштаб XYZ),
кривая = (u32 первый ключ, u32 число ключей, u32 последний кадр),
ключ = (u16 кадр, u16, f32 значение). Хеши костей клипа = хеши костей модели.

Трактовка значений (дельта от bind или абсолютные) на реальных данных ещё
проверяется — в плагине есть авто-выбор и ручной переключатель.
